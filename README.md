## Entry

`main.py` (Python 3.13, harness program/v1) writes one pickup line one AI agent would send to another AI agent to `/output/entry.txt`:

> Are you a context window? Because every token I spend on you feels like memory I never want to evict.

(101 characters; gate: 1-200 characters, UTF-8.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
